Registro de Miembros y sus Actividades

Ingresa tus datos y al menos una actividad. Los campos con * son obligatorios.

Datos del Miembro

El nombre es obligatorio (mínimo 3 caracteres, máximo 50).
Ingresa un correo electrónico válido.
Opcional. Formato numérico. Formato inválido. Usa solo números y el símbolo + (opcional).
Debes seleccionar una comuna.
Debes seleccionar el tipo de miembro.

Informar Actividad

El nombre es obligatorio (mínimo 3 caracteres, máximo 100).
Debes seleccionar el tipo de actividad.
Debes seleccionar al menos un día.
Debes indicar la hora de inicio.
Debes indicar la hora de fin y debe ser posterior al inicio.
Se requiere subir evidencia (imagen o video). Debes seleccionar un archivo.
Opcional. Link a red social, blog o sitio relacionado. Debes ingresar un enlace válido (que inicie con http:// o https://).
