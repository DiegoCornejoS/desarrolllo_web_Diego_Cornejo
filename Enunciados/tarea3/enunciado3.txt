Descripción 
 
El desarrollo de su Tarea 2 fue muy bien recibido y ahora es necesario completar las 
funcionalidades relacionadas a las estadísticas descritas en la Tarea 1. Para esto, debe 
complementar su proyecto hecho en Flask en la Tarea 2 para incluir la funcionalidad: 
 
●​ Estadísticas: Debe considerar 3 gráficos: 
○​ [0.6 punto] El primero es un gráfico de líneas que informa la cantidad de 
miembros registrados por día. En el eje X muestra los días y en el eje Y muestra 
la cantidad de miembros que se registraron en ese día.  
○​ [0.6 punto] El segundo es un gráfico de torta que muestra el total de actividades 
extraprogramáticas por tipo. 
○​ [0.8 punto] El tercer gráfico es uno de barras que muestra el total de actividades 
registradas por comuna. El eje X despliega las comunas para las cuales se han 
registrado miembros y para cada comuna en el eje Y muestra una barra con el 
total de actividades que corresponden a miembros de dicha comuna. 
Al final de esta pantalla debe agregar un enlace que permite volver a la portada del 
sistema. Debe usar Javascript (XHR o fetch) para generar los gráficos en el lado del 
cliente, llamando a una URL del lado del servidor que  obtiene la información desde la 
base de datos. 
 
Además, en esta tarea debe agregar una nueva funcionalidad que permita ingresar y visualizar 
comentarios a las actividades que se han ingresado al sistema. Para esto deberá implementar: 
  
●​ Agregar comentario [1.5 puntos]: Cuando se visualiza la información de una actividad 
extraprogramática, se debe incluir un formulario para agregar un nuevo comentario. 
Este formulario debe solicitar nombre de comentarista (caja de texto, obligatorio con 
largo mínimo 3 y máximo 80) y texto del comentario (Área de texto, 4 filas y 50 
columnas, dato obligatorio con al menos 5 caracteres). Junto con esta información debe 
agregar un botón con el texto “Agregar comentario”, al hacer clic debe validar que la 
información del nuevo comentario cumpla con las reglas, si las cumple, se debe hacer 
submit a una URL que es atendida por Flask. En esta URL se debe validar los datos del 
comentario en el lado del servidor y además debe insertar en la base de datos en la 
tabla comentario. Si no se cumplen las validaciones debe informar al usuario 
manteniendo visible el formulario para que lo pueda corregir. 
●​ Listado de comentarios asociados a una actividad extraprogramática [0.5 punto]: 
Cuando se consulta la información de una actividad, debe obtener los comentarios 
asociados a dicha actividad desde la base de datos y los debe incluir como un listado 

con la fecha, nombre del comentarista y texto del comentario. 
Las funcionalidades para agregar comentario y listado de comentarios las debe implementar 
usando llamadas asíncronas desde el lado del cliente. Esto lo puede hacer directamente 
usando Javascript con el objeto XHR o usando la función fetch o alguna biblioteca Javascript 
que usted decida.
